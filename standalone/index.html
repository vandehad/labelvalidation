How a conversion runs

  1. Generate labels. Feed in the old bin list, pick how tall the racks go, and produce the full label superset. Print those.
  2. Scan and pair. At each aisle, set the location, then scan old → new for every shelf. Duplicates and wrong-aisle labels are refused as you go.
  3. Reconcile. Load the printed list. Whatever was never scanned is unused and should be deleted, which is what makes the conversion exactly one-for-one.
  4. Export. Take the cross-reference out as .xlsx or .csv.

Scanner setup

  • Any USB scanner in keyboard-wedge mode works — no drivers, no configuration.
  • It must send Enter (CR) as a suffix. Most do by default; if not, scan the "Add CR suffix" barcode in the scanner's manual.
  • Tab as a suffix works too.
  • Test it in the Old bin field — if the code lands and jumps to New bin, you are set.

What gets refused

  • An old bin already paired — prevents double-scanning a shelf.
  • A new label already used elsewhere — prevents two shelves sharing a code.
  • A new label whose zone/aisle does not match the location you set.
  • A new label that is not in Z##/##/L/## form.
  • Old and new identical, which usually means a double-scan of the same label.
